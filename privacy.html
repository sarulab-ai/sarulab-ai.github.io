SARU LAB JARVIS

Privacy Policy

Last updated: 2026-08-27

Who this applies to

SARU LAB JARVIS is a single-operator internal tool run by SARU LAB (「AI社員研究所」) for its own social media accounts. It is not a public app — it does not have external end users, and it does not collect data about, or from, anyone other than the accounts SARU LAB itself owns and has explicitly connected to it. If you are a viewer of SARU LAB's public content on Instagram, YouTube, note, Threads, or TikTok, this policy does not describe any data collection about you personally — JARVIS only ever sees the same public, aggregate metrics (like counts, view counts, etc.) that each platform's own creator tools already show to any account owner about their own posts.

What JARVIS accesses via the TikTok API

Once TikTok approves this application, JARVIS is designed to use TikTok's official API for the following, and only the following, on SARU LAB's own authorized TikTok account:

DataPurpose
Video files and captions that SARU LAB itself has producedPublishing them to SARU LAB's own TikTok account
Post-level performance metrics that TikTok's API exposes for those posts (for example: view count, like count, comment count, share count)Measuring which content performs well, to improve future content
OAuth access/refresh tokens issued by TikTok for the authorized accountAuthenticating JARVIS's API requests

JARVIS does not request or process TikTok data beyond what is listed above. In particular, it does not collect data about other TikTok users, viewers, or accounts, and — per TikTok's own API — average watch time is not exposed through the API JARVIS uses and is therefore not collected.

How data is stored

  • OAuth tokens and API credentials are stored locally using the operating system's own encrypted credential store (macOS Keychain), the same mechanism SARU LAB already uses for its Instagram and YouTube integrations.
  • Credentials are never written to log files, committed to source control, or displayed in any public page — including this one.
  • Retrieved performance metrics are stored in SARU LAB's own private, non-public operational records for its own analysis. They are not published or shared externally.

Sharing with third parties

JARVIS does not sell or share any TikTok data with third parties. The only data flow is between JARVIS and TikTok's own API, for the sole purpose of publishing SARU LAB's own content and reading back its own posts' performance metrics.

Retention & deletion

SARU LAB retains performance metrics for as long as needed for its own content analysis. Because JARVIS only accesses SARU LAB's own authorized account, revoking that authorization in TikTok's own account settings stops all further data access immediately.

Changes to this policy

This policy will be updated if JARVIS's actual use of the TikTok API changes. The "Last updated" date above will be revised accordingly — no data collection beyond what is described here will begin without this page being updated first.
