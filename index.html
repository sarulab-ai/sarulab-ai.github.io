🐒 SARU LAB JARVIS
AI社員研究所 — Content Automation System

Educational content, made and managed by an autonomous AI operations system.

SARU LAB JARVIS is an internal automation tool built and operated by SARU LAB (「AI社員研究所」) — a Japan-based educational project that teaches AI-assisted work habits to non-technical professionals through short-form video and articles, featuring the character "サル所長" (Saru Shocho).

JARVIS plans, produces, quality-checks, publishes, and measures the results of SARU LAB's own educational content across the social platforms SARU LAB operates on. It is a single-operator tool: it only ever posts to accounts that SARU LAB itself owns and has explicitly authorized — it is not a public or multi-tenant service, and it does not act on behalf of anyone else's account.

Platforms this tool operates on

  • Instagram — live (Instagram Graph API)
  • YouTube — live (YouTube Data / Analytics API)
  • note — live (manual dashboard reporting, no API)
  • Threads — live (browser-based publishing)
  • TikTok — in setup (this application)

What JARVIS does

For each platform it is connected to, JARVIS follows the same loop: draft a short educational script → produce narration and video → run an automated + human-reviewed quality check against SARU LAB's own content guidelines → publish → retrieve whatever performance metrics that platform's official API makes available (views, likes, comments, etc.) → record the results so future content can improve. No step in this loop involves any account, content, or data other than SARU LAB's own.
